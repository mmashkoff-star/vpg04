# VPg04

RAG-помощник. Сначала ищет ответ в индексе Pinecone. Если подходящих фрагментов нет и это не запрос факта о собаках, ищет в интернете. По просьбе читает страницу по ссылке и сохраняет её в тот же индекс. Чат и эмбеддинги идут через [ProxyAPI](https://proxyapi.ru). Телеграм-бот в `bot.py` отвечает на сообщения, запоминает факты о пользователе и в конце ответа указывает источник.

`example.py` — учебный сценарий из документации LangChain: он индексирует страницы docs.langchain.com в память и отвечает на один вопрос. Рабочий агент — `main.py`.

## Как бот отвечает

1. Запрос случайного факта о собаках. Бот делает GET `https://dogapi.dog/api/v2/facts` и не ищет ни в базе, ни в интернете. Факт приходит по-английски, бот пересказывает его на языке вопроса. Источник: `random_dog_fact`.
2. В Pinecone есть близкие фрагменты. Ответ строится только по ним, одним запросом к модели. Слабые совпадения отбрасываются. Источник: `Pinecone` и адрес страницы или пометка «факты о пользователе» / «заметка».
3. В базе ничего подходящего нет. Бот ищет в интернете: сначала русская Википедия, затем английская. Источник: `интернет` и ссылка на статью.
4. Ссылка в сообщении. Страница читается, режется на чанки и записывается в индекс. Если сайт отвечает 401 или 403 (антибот-проверка), бот просит прислать текст командой `/add_text`. Источник такой страницы: `интернет`.

Фразы вроде «меня зовут…», «я живу…», «мне нравится…», «запомни…» сохраняются как эмбеддинги и не смешиваются с фактами других пользователей. Страницы по ссылкам видны всем, заметки и факты — только их автору.

## Требования

- Python 3.11
- Индекс Pinecone с размерностью эмбеддингов `text-embedding-3-small` (1536)
- Ключ ProxyAPI
- Токен Telegram, если запускается бот

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install deepagents "langchain[openai]" langchain-text-splitters requests python-dotenv langchain-pinecone pinecone numpy pyTelegramBotAPI
```

Скопируйте шаблон настроек и заполните ключи:

```powershell
copy .env.example .env
```

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `PROXYAPI_API_KEY` | да | Ключ ProxyAPI. Если пусто, берётся `OPENAI_API_KEY` |
| `PINECONE_API_KEY` | да | Ключ Pinecone |
| `PINECONE_INDEX_NAME` | да | Имя индекса. Другое имя той же настройки: `PINECONE_INDEX` |
| `OPENAI_BASE_URL` | нет | По умолчанию `https://api.proxyapi.ru/v1` |
| `OPENAI_MODEL` | нет | По умолчанию `openai/gpt-5.5` |
| `OPENAI_EMBEDDING_MODEL` | нет | По умолчанию `openai/text-embedding-3-small` |
| `PINECONE_NAMESPACE` | нет | Пространство имён в индексе |
| `TELEGRAM_BOT_TOKEN` | для бота | Токен от @BotFather |
| `LOG_DIR` | нет | Каталог логов. По умолчанию `logs` рядом с `bot.py` |

## Запуск

Проверка связи с индексом. Печатается число найденных фрагментов, текст ответа модели не нужен:

```powershell
python main.py
```

Телеграм-бот. Одновременно должен работать только один процесс: второй опрос с тем же токеном конфликтует с первым.

```powershell
python bot.py
```

После изменения кода остановите процесс и запустите его снова.

### Команды бота

Команда из меню без аргумента не уходит в обычный ответ. Бот просит прислать данные следующим сообщением. Отмена ожидания — `/cancel` или любая другая команда. Аргумент можно написать сразу: `/add_text текст`.

| Команда | Что делает |
| --- | --- |
| `/help`, `/start` | Меню команд |
| вопрос обычным текстом | Сначала Pinecone. Если подходящего ответа нет и это не факт о собаках, поиск в интернете. Источник указан в конце |
| `/search <запрос>` | Фрагменты из базы без полного ответа агента |
| `/add_url <URL>` | Прочитать страницу и записать её в базу |
| `/add_text <текст>`, `/add` | Сохранить произвольный текст |
| `/profile` | Факты о вас и счётчики |
| `/summary` | Короткое резюме по сохранённым фактам |
| `/suggestions` | Вопросы для изучения по материалам базы |
| `/engagement` | Уровень активности: низкий, средний или высокий |
| `/forget_me` | Удалить ваши факты, заметки и локальную статистику. Общие страницы базы остаются |
| `/cancel` | Отменить ожидание текста, ссылки или запроса |

Фразы вроде «меня зовут…» или «запомни…» бот записывает сам и отвечает «Запомнил», если в сообщении нет вопроса и ссылки.

### Логи

Каталог `logs` (или `LOG_DIR`):

- `bot.log` — служебные сообщения, те же строки идут в консоль
- `chat.log` — переписка: чат, пользователь, текст сообщения и ответ
- `activity.json` — локальные факты профиля и счётчики сообщений, заметок, страниц и поисков

Файлы логов растут с ротацией по 2 МБ, до 5 архивов. В них есть личная переписка, в git их лучше не класть.

Ответ на сообщение без Telegram:

```python
from main import RAGAgent

agent = RAGAgent()
print(agent.answer("Что лежит в базе про субагентов?"))
```

Учебный пример с документацией LangChain в памяти:

```powershell
python example.py
```

Он скачивает страницы документации и вызывает модель. Для этого нужны ключ ProxyAPI и доступ в интернет.
